## 🚀 Quick Start

### 1. Run Remotion Studio (Visual Preview)
\`\`\`bash
npm run dev
\`\`\`
Opens Remotion Studio at `http://localhost:3000` for frame-by-frame scrubbing and live preview.

### 2. Render Full 1080x1920 Master MP4
\`\`\`bash
npx remotion render src/index.ts SafarSathiHoneymoonReel out/SafarSathi_Honeymoon_Reel_Master.mp4
\`\`\`

### 3. Render a Still Frame (for Social Posts / Thumbnail)
\`\`\`bash
npx remotion still src/index.ts SafarSathiHoneymoonReel out/frame_50.png --frame=50
\`\`\`
